# Unity Visual Novel Dialogue System

## A basic dialogue system for a visual novel game that uses the narrative scripting language, Ink.

With the help of Ink and a handful of YouTube video tutorials, this dialogue system currently supports the following features:

* Displaying dialogue to the screen via typewriter effect
* Displaying interactable dialogue choices when applicable
* Receives user input to skip text or autoplay lines without the user having to prompt dialogue forward
